## Redis

連線設定在 `.env`：在本機執行的伺服器只讀 `REDIS_URL`（必填，缺少時拒絕啟動並指出變數名稱）；容器裡的 `server` 固定連到同一份 compose 的 `redis` 服務。`REDIS_PORT` 是該服務在本機迴路上的埠。啟動時 Redis 連不上，伺服器不會啟動，只指出依賴的名稱，不印出網址；啟動之後 Redis 失聯，健康檢查與速率限制回 503，行程不會結束。
