## GET /api/health

回報服務還活著。這是封套規則的例外：它不在 `/api/v1` 之下，回應是裸的狀態物件，讓負載平衡器與探針直接讀。它不碰任何相依服務，因為目前沒有任何相依服務；資料庫等相依服務加入後，由對應的 overlay 補上檢查，相依服務失效時回 503 `{"status":"unavailable"}`。

這條路由不受速率限制：探針收到 429 會被當成服務已死。

參數：無。

回應 200：

```json
{ "status": "ok" }
```

可能的失敗：沒有。
