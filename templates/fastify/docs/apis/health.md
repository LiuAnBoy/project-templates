# health

共用規則：[conventions.md](./conventions.md)。這條路由公開，沒有認證，日後加入認證時仍然公開。

| 方法  | 路徑          | 說明                             |
| ----- | ------------- | -------------------------------- |
| `GET` | `/api/health` | 回報服務與它依賴的服務是否可用。 |

## GET /api/health

回報服務是否可用。這是封套規則的例外：它不在 `/api/v1` 之下，回應是裸的狀態物件，讓負載平衡器與探針直接讀。

路由會執行 `src/infra/` 提供的依賴檢查，每個檢查都有逾時上限。沒有任何檢查，或全部通過，回 200 `{"status":"ok"}`；任何一個失敗或逾時，回 503 `{"status":"unavailable"}`。本文不含檢查的名稱，名稱只寫在日誌。並行的請求共用同一次檢查，結果（失敗也一樣）重用一秒，所以任何 client 都不能讓每個請求各打一次依賴服務。

這條路由不受速率限制：探針收到 429 會被當成服務已死，也避免相依服務出問題時所有實例被重啟。

參數：無。

回應 200：

```json
{ "status": "ok" }
```

回應 503：

```json
{ "status": "unavailable" }
```

可能的失敗：依賴檢查失敗或逾時時回 503，本文如上。
